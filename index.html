TypeScript · LinkedIn · MCP · SDK

Your LinkedIn posts, from your AI agent

An unofficial MCP server and TypeScript SDK to create, edit and delete your own LinkedIn posts, through LinkedIn's official API and an app of your own.

Get started →GitHub
$ npm install @hoyasumii/linkedin
linkedin-mcp

MCP server

Let Claude Code, Codex, OpenCode or any MCP client post for you: text, images, a video, a document or a link; edit the text later, or delete the post.

npx -p @hoyasumii/linkedin linkedin mcp config --web
npx -p @hoyasumii/linkedin linkedin mcp install
@hoyasumii/linkedin

SDK

A typed client for LinkedIn's Posts API, generated by orval from an OpenAPI spec: uploads, multi-part videos and the little text format handled for you.

const linkedin = createLinkedInClient({ accessToken });
const { urn } = await linkedin.createPost({ text: "Shipped (finally)!" });
linkedin

CLI

Sign in to LinkedIn from a local web page, and register the MCP server in your AI clients in one go.

linkedin mcp status
linkedin mcp install --client claude
